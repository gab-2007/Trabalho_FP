# Trabalho de Fundamentos de Programação

## Abrir no VS Code

1. Extraia a pasta `trabalho de fp`.
2. No VS Code, escolha **Arquivo > Abrir Pasta** e selecione essa pasta.
3. Abra o terminal integrado e execute:

```powershell
python main.py
```

No Windows, também pode usar `py main.py`.

## Arquivos do projeto

- `main.py`: menu principal e ligação entre as seis partes.
- `animais.py`: cadastro, listagem, edição e exclusão de animais.
- `cuidados.py`: registro e manutenção dos cuidados.
- `alertas.py`: consulta de alertas e registro de previsões.
- `sugestoes.py`: comparação entre animais e preferências de adotantes.
- `adocoes.py`: cadastro, listagem e histórico de adoções.
- `agendamentos.py`: agendamento, edição, listagem e cancelamento de visitas.

Os módulos devem permanecer juntos na mesma pasta. Os arquivos `.txt` são criados ou atualizados pelo programa na pasta de execução. Cadastre um animal pela opção 1 antes de usar sugestões, adoções, alertas ou visitas.
